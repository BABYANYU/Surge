# 丰巢广告实验

本版是响应改写实验，不是已验证的开屏修复。只作用于 `https://dsp.fcbox.com/adSearch/get` 与 `/adSearch/getMulti`，不拒绝任何连接、不拦微信共享图片/视频域名，不操作登录、地址、订单、支付或会员接口。

## 证据与假设

授权 HAR 本机离线分析得到 65 条响应，其中三个广告检索响应成功码为字符串 `370100000`，广告数据为数组或 null，`extendsMap` 包含字符串类型的 `fcDspFlag`、`interstitialErrSwitch`，其中一条另有 `wxAdsFlag`。客户端实际如何消费这些配置、是否有缓存及开屏是否由其控制，尚未证实。

试验方式：保留原成功码、消息、未知字段；非空广告数组清空，原有的上述标志 true 改为 false（保持字符串/布尔类型），不创建缺失标志。未知结构、异常 JSON、非成功响应透传。这可能无效，也可能改变广告回退行为，需用户观察，不能当作因果结论。

## 验证

17 组合成测试通过；在原 HAR 离线执行，恰好修改三个广告响应，62 条响应未动。测试不重放 API，不发信、不下单、不付款；原始 HAR、响应样本及个人信息不入库。

安装后开启 MITM 并信任证书，停用其他丰巢广告模块；完全退出小程序后重开。观察开屏视频及首页是否正常，异常时关闭本模块。不需要为测试进行真实取件/寄件或支付。

脚本采用 main 稳定链接，未承诺只手动更新；也未自动安装、修改活动 Surge.conf 或开启 HTTP 捕获。
